3.1 Linear Equations in Standard Form

LO: I can graph linear equations in standard form and connect the solutions of an equation to points on its graph.
Standards: A.REI.D.10, A.CED.A.3
Ax + By = C
x-intercept: put y = 0 and solve. y-intercept: put x = 0 and solve. A point is a solution if it makes the equation true.

Part A · Standard form

Warm-up. Standard form is Ax + By = C: x and y on the left, a number on the right. Tap the correct answer.

Part B · Is the point a solution?

Put the x-value and the y-value into the equation. If both sides are equal, the point is on the line.

Part C · Find the intercepts

x-intercept: put y = 0. y-intercept: put x = 0. Type one number.

Part D · Special lines

A = 0 (no x): horizontal line
B = 0 (no y): vertical line
C = 0: line through the origin
