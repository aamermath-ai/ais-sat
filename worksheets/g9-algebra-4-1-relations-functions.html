4.1 Relations and Functions

LO: I can tell if a relation is a function, find its domain and range, and use function notation f(x).
Standards: F.IF.A.1, F.IF.A.2 · In simple words: a function gives ONE output for every input.
Function: 1 input → 1 output (outputs may repeat)
Domain = all the x-values (inputs). Range = all the y-values (outputs). Write a repeated number only once.

Warm-up. Look at the ordered pairs. Tap or type the correct answer.

Part B · Mapping diagrams

Each arrow goes from an input to its output. A function has only one arrow from each input. Two inputs can point to the same output.

Part C · Tables and ordered pairs

Look at the x column. If an x-value repeats with a different y-value, it is not a function.

Part D · Vertical line test

Move a vertical line (a ruler) across the graph. If it ever touches the graph at 2 or more points, it is not a function.

Part E · Function notation f(x)

f(x) is read “f of x”. To find f(3), put 3 in place of x and work it out. Use brackets for negative numbers.
